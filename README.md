# AI News Publisher

This is a Flask app that fetches top trending news, summarizes them using Ollama LLM, generates images for each news card, and creates individual audio summaries.  

## Features
- Dynamic categories (Tech, Business, Stocks, Entertainment, etc.)
- AI-generated summaries
- AI-generated images with gradients
- Text-to-Speech audio per news card
- Responsive UI with Font Awesome icons

## Requirements
- Python 3.11+
- Flask
- BeautifulSoup
- Ollama LLM
- gTTS
- Pillow
